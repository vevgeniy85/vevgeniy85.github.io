# Extended Solution

Статическое многоязычное портфолио на Eleventy 3 и Tailwind CSS 4. Браузеру не нужен фреймворк: Eleventy создаёт HTML во время сборки, Tailwind — локальный CSS. JavaScript отвечает только за мобильное меню, фильтры и форму.

Документация: [Eleventy](https://www.11ty.dev/docs/), [Tailwind CLI](https://tailwindcss.com/docs/installation/tailwind-cli).

## Запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Откройте адрес, который Eleventy покажет в терминале (обычно http://localhost:8080). Изменения шаблонов, контента и стилей обновляются автоматически.

```sh
npm run build
npm run check
```

Готовый сайт находится в `_site/`. Исходное техническое задание сохранено в `readme.md`.

Браузерные проверки: `npm test`. По умолчанию используется установленный Microsoft Edge. Для другого Chromium измените `channel` в `playwright.config.js`. Проверки охватывают все языковые маршруты на ширинах 375, 430, 768, 1024 и 1440 px, фильтры, мобильное меню, переключение языков и состояния формы.

При создании проекта `npm audit` сообщил о 12 предупреждениях в инструментах сборки (braces и sprintf-js и зависимости, использующие их). На момент проверки исправленных стабильных версий этих двух пакетов в npm не было. В публикуемый сайт Node.js-зависимости не входят; обновления инструментов стоит отслеживать. `npm audit fix --force` не применялся, поскольку он предлагает откат Eleventy до несовместимой версии.

## Где редактировать

- `src/_data/site.js`: имя, контакты, показатели, опыт работы, адрес сервиса формы и origin сайта для canonical/hreflang (например `https://username.github.io`, без пути репозитория).
- `src/lib/content.js`: тексты EN/UK/RU и демонстрационные проекты. В URL украинский язык обозначен `uk`, в переключателе — UA.
- `src/pages.11ty.js`: секции и структура страниц.
- `src/lib/ui.js`: шапка, подвал, карточки, кнопки и общие компоненты.
- `src/styles.css`: Tailwind, цветовые токены и общие стили.
- `src/assets/`: локальная графика и браузерный JavaScript.

Основной шрифт — локальный variable Manrope с латиницей и кириллицей. Семь иконок технологий взяты из Font Awesome Free Brands и встроены как SVG во время сборки. `scripts/vendor-assets.mjs` копирует шрифты и лицензии перед сборкой CSS и запуском разработки. У кнопок uppercase и плавное изменение оттенка при наведении без движения кнопки и стрелки. Переходы отключаются при `prefers-reduced-motion`.

Акцентный цвет интерфейса меняется в `src/styles.css`: `--color-accent: #a855f7;`. Hover-оттенок, полупрозрачные фоны, тени и рамки вычисляются от него автоматически. При `npm run dev` изменение CSS автоматически пересобирается. Цвета внутри изображений и SVG-превью проектов независимы от темы.

Посетитель может выбрать один из пяти цветов: на десктопе кнопкой палитры в шапке, на мобильном — внутри меню. Выбор сохраняется на год в cookie `xt-ui-accent` с путём текущего сайта, `SameSite=Lax` и `Secure` для HTTPS. Сохранённый выбор имеет приоритет над исходным `--color-accent` и применяется до отображения страницы через `src/assets/theme.js`. На светлых акцентных кнопках текст тёмный для читаемости. Cookie содержит только название цвета.

Основной язык английский: `/`. Другие версии: `/uk/` и `/ru/`. Переключение языка сохраняет текущую страницу. У каждого из шести демопроектов и опубликованных сайтов «Поїхали з нами» и NutraHarmony есть отдельная страница. Всего генерируется 39 страниц и `404.html`.

Реальные проекты хранятся в `src/lib/content.js` со своими текстами EN/UK/RU, адресами и настоящими скриншотами `src/assets/poehalisnami.webp` и `src/assets/nutraharmony.webp`. Для «Поїхали з нами» пользователь подтвердил полную разработку сайта, собственной WordPress-темы и плагинов. Для NutraHarmony — редизайн темы Dawn, кастомные секции и кастомизацию Recharge. Для обновления скриншота: `node scripts/capture-project.mjs poehalisnami` или `node scripts/capture-project.mjs nutraharmony` (нужен сетевой доступ).

По пожеланию пользователя в превью этих двух проектов сейчас отображаются прежние демомакеты `travel-agency-home.svg` и `online-store-home.svg`. Настоящие скриншоты сохранены; для возврата поменяйте `image` у проекта на соответствующий `.webp`.

Число специализаций отражает WordPress и Shopify. Опыт, число завершённых работ, контакты и профессиональная хронология не выдуманы: пока не заполнены. Превью и описания явно отмечены как демоконцепции.

## Форма

По умолчанию ничего не отправляет и не сохраняет. Валидирует обязательные поля, показывает ошибки и сообщает, что доставка не подключена. GitHub Pages не выполняет серверный код.

Для подключения укажите `formEndpoint` в `src/_data/site.js` и адаптируйте `src/assets/contact-adapter.js` под выбранный сервис. Текущий адаптер отправляет JSON и считает отправку успешной только при HTTP 2xx с JSON `{ "success": true }`. Сервис должен разрешать CORS для сайта. Приватные API-ключи нельзя помещать в эти файлы. Серверная валидация и защита от спама нужны на стороне сервиса.

## GitHub Pages

Публикация пока не выполнялась. После создания репозитория с веткой `main` включите Settings → Pages → Source → GitHub Actions. Файл `.github/workflows/pages.yml` соберёт, проверит и опубликует `_site/` при push или ручном запуске. `configure-pages` определяет подпапку репозитория автоматически; локальная сборка работает в корне.

Проверка подпапки в PowerShell:

```powershell
$env:SITE_PATH_PREFIX = '/extended-solution/'
npm run build
npm run check
Remove-Item Env:SITE_PATH_PREFIX
npm run build
```

SVG-превью — локальные демонстрационные макеты интерфейсов, не скриншоты клиентских работ. Для их регенерации и сжатия hero: `node scripts/assets.mjs`. Замените их реальными скриншотами перед публикацией настоящего портфолио.
